# Plans and methods

This folder holds four kinds of document. The [roadmap](roadmap.md) is the order of the build; the others either plan work outside the build, say how work is done, or describe a standing part of the project. The results of design review rounds are in [docs/reviews/](../reviews/README.md).

| Kind | Document | What it holds |
| --- | --- | --- |
| The order of the build | [build-plan.md](build-plan.md) | What is left, in eight stages, at three levels: what a person can do at each stage, the packages in order, and the tasks inside each. The file to work from |
| | [roadmap.md](roadmap.md) | Every work package to version 1.0: what it builds, what it needs, what proves it, and its state |
| Plans outside the build | [adoption.md](adoption.md) | How the product is to be found, tried, and trusted; its packages enter the roadmap when taken up |
| | [network-awareness.md](network-awareness.md) | The design proposal for owner decision 0222, at its first round; not in force |
| How work is done | [working-method.md](working-method.md) | The loop every slice follows, and the kinds of change to the design |
| | [design-review-lenses.md](design-review-lenses.md) | How a design review round is run, and the lenses with their last use |
| Standing descriptions | [test-application.md](test-application.md) | The test application's cases and the driver conformance suite, with what is built |
| | [publishing-setup.md](publishing-setup.md) | Where each package name stands, and how releases authenticate |
| | [open-questions-for-the-owner.md](open-questions-for-the-owner.md) | What is still waiting for the owner; the eighteen questions of 2026-11-18 are answered in decision 0242 |
| | [idea-rounds.md](idea-rounds.md) | The log of the ten-minute rounds in which a new idea is put forward, tested, and taken up or ruled out |
