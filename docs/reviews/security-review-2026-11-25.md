# Design review: the security reviewer, 2026-11-25

The first round by lens 8 of the [design review lenses](../plan/design-review-lenses.md). The lens asked about the company-server path, which is after the first release; this round read the one-machine preview instead, as an organization's security team would before letting release 0.1 ([decision 0476](../decisions/0476-version-0-1-is-a-preview-and-the-checks-a-person-makes-move-to-before-1-0.md)) onto a machine, and the lens's question now says it covers both. It is not the outside review, package 9.6, which is still owed.

## What was read

Rules 3, 4, 5, and 7; spec part 5 whole ([501](../spec/5-security/501-security-model.md), [502](../spec/5-security/502-defending-against-a-manipulated-agent.md), [503](../spec/5-security/503-approval-and-sign-in-surfaces.md)); [section 222](../spec/2-kernel/222-front-doors-and-the-local-engine.md) on the local channel and the person surface; [section 216](../spec/2-kernel/216-the-vault-and-its-keys.md) on the vault. In the code: the person surface (`crates/a2m-local/src/surface.rs`: the guard of `Host` and `Origin`, the headers of every page, the one-time code and value, the presses), the socket and the pipe (`os/unix.rs`, `os/windows.rs`), the polkit prompt and its policy file, the start of an engine on demand and how the passphrase reaches it (`start.rs`, `anything2mcp/src/cli/`), the passphrase route of the vault, and the release workflow with [publishing setup](../plan/publishing-setup.md) and [RELEASING.md](../../RELEASING.md). Then the README's promises and SECURITY.md against all of it.

## What held

Each of these was read in the code and found as the documents say:

- The person surface binds `127.0.0.1` on a port the system gives, answers only at a 128-bit code, refuses a request whose `Host` is not its own exactly, refuses a press with no `Origin` or another one, and serves every page with `no-store`, a policy that runs no script, loads nothing, and lets no page frame it, `nosniff`, and `same-origin` referrers. A press needs the one-time value of the page served last, compared in constant time and spent either way.
- The socket's folder is made through its handle, refusing a link, with mode 0700; the socket is 0600; the engine reads the peer's user from the kernel before any byte. The pipe has a protected access list naming only the user, the first-instance flag, and refuses remote clients; the client checks the user of the pipe's server process.
- The passphrase is taken out of the program's environment before any thread starts, is handed to an engine started on demand on a pipe, and the engine is started with a cleared environment. The derivation is Argon2id with the cost its file records, and a file it cannot read derives nothing.
- polkit is asked without interaction first, so a yes nobody was asked for proves nobody; the policy file is installed by a command that copies it into a root-owned temporary file and checks its digest before installing.
- A panic's message is never written, since the engine's output file has no redactor.
- The release workflow pins every action by commit, keeps no credential in the checkout, gives `contents: read` at the top and `id-token: write` only to the jobs that publish, and uses no cache.

## What this round did not do

- The company-server path: not built, and after the release.
- The macOS and Windows presence prompts by a person (H-12), plug-ins, and imports of targets written by someone else: not built or after the release.
- Rules 3 and 7 were read through section 502's map of defences to tests and section 208's ledger rules, not test by test; no finding.
- No code was changed. SR2, SR4, and SR5 are in `a2m-local`, SR3 in the release workflow, each with a proof to write first.

## Returns

Ten findings, one of them high, and the high one is outside the product: the release pipeline's gate rested on settings the documents called optional. The product's own barriers held where they were read. The next gain is more likely from the outside review (9.6), from a person running the Windows and macOS prompts, and from building SR5, than from another round of this lens before the server exists.
