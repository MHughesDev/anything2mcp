# 0018. License: Apache-2.0

**Status:** Superseded by [0057](0057-the-licence-is-mit.md) on 2026-11-17. Was: Accepted. Decided in the system design; the owner delegated these choices.

**Date:** 2026-11-15

## Context

The project is open source and will be used inside companies.

## Decision

Apache-2.0.

## Consequences

- Includes an explicit patent grant.
- Compatible with the MIT-licensed code Web2MCP may build on.

## Alternatives considered

- MIT: simpler, no patent grant.

## Revisit if

The owner prefers a different license before the first release.
