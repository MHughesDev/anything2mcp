# 0200. Evidence names its binding, and a recorded fixture says nothing of the original

**Status:** Accepted. Design decision. The owner had not read this record when it was merged.

**Date:** 2026-11-18

**Changes:** the designs of [`a2m-actions`](../architecture/crates/a2m-actions.md), [`a2m-engine`](../architecture/crates/a2m-engine.md), [`a2m-files`](../architecture/crates/a2m-files.md), and [`a2m-ledger`](../architecture/crates/a2m-ledger.md); the guides on operations, on target files, and the agent guide; the test section of the [file formats](../reference/file-formats.md#testsyaml-and-fixtures); the rows of `draft.try`, `fixture.record`, and `binding.promote` in the [action catalog](../reference/action-catalog.md) and the clients' generated actions; a failure code and a lint code of the [technical reference](../reference/technical-reference.md); sentences of spec sections [201](../spec/2-kernel/201-archetypes-and-modes.md), [219](../spec/2-kernel/219-the-evidence-ladder.md), and [403](../spec/4-building-tools/403-testing-and-publish-gates.md). Adds to the engine `JobSpec::binding`, `BindingPin`, `binding_digest`, and `default_binding`; to `a2m-files` the test key `binding`, `Compiled::test_bindings`, and the lint code `kernel.test_binding_unknown`. Supersedes, of [decision 0196](0196-the-engine-and-the-registry-after-the-acknowledgement-and-the-first-hour.md) point 5, the scrubbing rules, and of [decision 0199](0199-the-halves-left-for-each-other-are-joined.md), "a choice by another declared code". Builds the check [decision 0203](0203-two-packs-may-each-draft-a-file-kind-of-one-name-for-their-own-surfaces.md) left owed, and adopts `Scheduler::resume` of [decision 0201](0201-a-resume-is-never-lost-the-browser-takes-no-proxy-and-no-product-build-speaks-a-stands-protocol.md). Takes up the findings of the kernel's fourth safety pass in these crates, but SC-1, PX-1, and FE-1 (decision 0201). The pass read the code and ran nothing; each finding below was first shown by a test that fails without its fix, or refuted by the code.

## Consequences

- Every project's gate was run again: `targets/example` and the product's test projects pass; no test was loosened.
- Owed by other crates: `a2m-core`'s `TestPlan` should carry the tested binding, so that the plan, and not a side table of `a2m-files`, holds it; `a2m-provider`'s `RecordedElsewhere` should gain a variant that says another record holds a value and names none, for a record of another person's run; `a2m-provider`'s `CheckedPath` should offer a write that creates a file new through its folder handle, which `fixture.record` now does with an exclusive create and an identity check after; the stream pack's refusal should name no run of the answer.
- A binding's digest takes in the whole pack section it refers to: a change to any call of a calls file changes the digest of every binding over it, and a trial made before must be made again.

## Revisit if

A pack's section gives the kernel one entry's own bytes, so that a binding's digest can cover only what it refers to; or `TestPlan` carries the tested binding.
