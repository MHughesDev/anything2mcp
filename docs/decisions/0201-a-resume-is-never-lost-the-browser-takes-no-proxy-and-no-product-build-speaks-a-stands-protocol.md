# 0201. A resume is never lost, the browser takes no proxy, and no product build speaks a stand's protocol

**Status:** Accepted. Design decision. The owner had not read this record when it was merged.

**Date:** 2026-11-17

**Changes:** the designs of [`a2m-sched`](../architecture/crates/a2m-sched.md), [the browser engine crate](../architecture/crates/a2m-pack-web-browser.md), and [`a2m-pack-stream`](../architecture/crates/a2m-pack-stream.md); the stand `targets/example-broker`; sentences of spec sections [309](../spec/3-packs/309-the-stream-pack.md) and [603](../spec/6-running-it/603-networking.md) and of the [technical reference](../reference/technical-reference.md). Supersedes the sentence of [decision 0197](0197-no-client-takes-a-proxy-from-the-environment-and-stand-only-protocols.md) that keeps `example-broker/1` out of the product with the feature `example-protocol`, and adds to [decision 0193](0193-the-core-the-contract-the-compiler-and-the-scheduler-after-the-second-pass.md)'s wake of a waiting reconcile. Takes up the findings SC-1, PX-1, and FE-1 of the kernel's fourth safety pass, which read the code and ran nothing. Each was first shown by a test that failed before its fix.

## Decision

| Finding | Verdict and test | Built | Alternative weighed |
| --- | --- | --- | --- |
| SC-1: a resume's wake is lost when the reconcile it races ends between its two transactions | Confirmed. `a_resume_that_races_the_end_of_the_reconcile_it_finds_is_never_lost`: a transaction of the test's own holds the store's one writer; the resume hands over its transaction while the reconcile is leased, the reconcile's end hands over its own after that, then the writer is let go. Nothing sleeps and the clock does not move. Before: the resume was refused as `schema_invalid` and the next reconcile waited ten seconds | `Scheduler::resume` finds the run's one job and acts in the same transaction in which it would queue its own: a waiting reconcile is woken to now; a leased one is remembered, and the reconcile it queues on ending in doubt, or after its lease is lost, takes no growing wait. A quarantine still holds (decision 0193). It answers `Resumed::Queued(job)` or `Resumed::Reconciling { job, leased, from, quarantine_left }`; `Reconciling::failure()` is `busy`, `run_reconciling`, for a door, and says how long a quarantine remains. `enqueue` does the same and still answers a reconcile as `input`, `schema_invalid`, which `run.resume` reads as "the run has its job", now in words that say when the reconcile is handed out. The mark is kept in the scheduler's memory, read and changed only inside the store's write transactions, which its one writer runs in order (`a_resume_names_the_reconcile_it_finds_and_inside_a_quarantine_says_how_long_remains`) | A column on `jobs` for the mark: durable, but a migration in `a2m-ledger`, and the wake serves the call that asked, which a restart ends too; the next resume finds the waiting reconcile in the store. Changing `enqueue`'s code to `run_reconciling`: `run.resume` would then show the person a failure instead of waiting, and the product's end-to-end test of a lost lease would fail; that crate changes it when it calls `resume` |
| PX-1: the engine's browser takes the system's proxy | Confirmed, on Linux with the variables a browser reads there: `the_browser_takes_no_proxy_from_the_environment_around_it` sets `http_proxy`, `HTTPS_PROXY`, `ALL_PROXY` and the rest for the browser, naming a listener that stands for a proxy, and asks for a page at a name no resolver knows. Before: five connections, the page's request and the browser's own among them | `--no-proxy-server` and `--disable-extensions` in `FIXED_ARGUMENTS`, held by `every_launch_connects_directly_and_runs_no_extension` | Clearing more variables: the supervisor already clears the environment on Linux, and on Windows and macOS the browser reads the system's settings, not variables; only the flag refuses those |

What was run, on Chrome for Testing 153, headless, with a listener on a loopback port of its own and a page at `http://a2m-proxy-check.invalid/`:

| Way a browser takes a proxy | Without the flag | With `--no-proxy-server` | The launch closes it |
| --- | --- | --- | --- |
| Proxy variables in the browser's environment | The listener saw the page's request, a time request of the browser's own, and a tunnel for its component updates, also with `--disable-background-networking` | Nothing | Yes |
| A proxy stored in the profile's settings (`Default/Preferences`) | The listener saw the page | Nothing | Yes. A fresh profile the engine makes stores no proxy (`provisioning_domain_proxy_configs` is empty) |
| An extension that sets a proxy | — | The listener saw the page: an extension outranks the flag | Yes, with `--disable-extensions`: nothing. The engine installs none; another program can install one into every profile |
| A machine policy (`ProxySettings` in the browser's managed policies folder) | The listener saw the page | The listener saw the page: a policy outranks every launch argument | No. It is the machine administrator's setting, made where the engine has no say. A check of the policy before start is owed to the web pack's `doctor` lines, not built |
| Windows' and macOS's own settings, automatic discovery included | Not run here | The flag is documented to outrank them | CI's browser tests on Windows and macOS pass with both flags, which shows the flags are taken and the browser works; they set no system proxy, so they do not show it refused |

| FE-1: `cargo build --workspace` makes a program that speaks `example-broker/1` | Confirmed by reading: a feature a workspace member turns on is unified into every package the command builds. Ruled by the lead: no documented build command makes a product program that offers a stand's protocol | No feature. The protocol stays in the pack, always compiled, and is offered only by a registration that asks: `StreamPack::with_test_broker()`, `register_with_test_broker`. `register`, the product's one call, offers `nats` alone, unless the stand's harness has started a broker in the same process: `TestBroker::start` calls the hidden `offer_test_broker_protocol_in_this_process`, so that the product's end-to-end test, which builds the product's own registry in its process, reaches its broker without a change to the product crate. The shipped program never links the stand. `the_ordinary_registration_offers_only_the_real_protocol_and_refuses_the_stands`, in a test binary that starts no broker: the compiler answers `kernel.unknown_value`, `Use one of: nats.`, and the driver refuses a plan that names it, unsent, `protocol_unknown`. A unit rule holds that only the stand's harness names the switch, and no manifest names a feature for it. `cargo build --workspace`, then the built program's `draft lint` of a broker target naming the stand's protocol: `kernel.unknown_value`, `Use one of: nats.` | Moving the protocol into the stand's crate, so that the pack ships none of it: it needs the wire interface, the pack's JSON value, and the channel shape public, a dozen types and their fields, which is not a small change. A feature the product's development dependencies turn on: unified the same way |

## Consequences

- The scheduler has `resume`, `Resumed`, `Reconciling`, and the code `run_reconciling`. `run.resume` in the action registry should call `resume` and wait on `Resumed::Reconciling` instead of matching `schema_invalid`; when the wait ends inside a quarantine, `Reconciling::failure()` says how long remains. Until then it is served by `enqueue`, which no longer loses the wake.
- Every browser the engine starts connects directly and runs no extension. A person who can reach a site only through a proxy cannot reach it from the engine's browser until `network.proxy` is built (decision 0197). A machine policy that sets the browser's proxy is not refused.
- The pack's tests register with `register_with_test_broker`. Any process that starts the test broker offers its protocol to every later registration of the pack in that process; only test processes start it.

## Revisit if

The product's engine options take a test's registration (then `other_packs.rs` passes `register_with_test_broker` and the switch goes); the scheduler's jobs table gains a column for a resume's mark; or a browser version stops honouring `--no-proxy-server` or `--disable-extensions`, which the proxy test shows on Linux.
