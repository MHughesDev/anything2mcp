# anything2mcp

This release holds the name `anything2mcp` on PyPI. It contains no working software.

Anything2MCP is being built in the open at <https://github.com/MHughesDev/anything2mcp>. It will latch onto existing software and systems and expose them to AI agents as deterministic, verified MCP tools. When there is something to use, it will be published here under a later version.
