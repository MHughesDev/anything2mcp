# web2mcp

This release holds the name `web2mcp` on PyPI. It contains no working software.

Web2MCP is being built in the open at <https://github.com/MHughesDev/web2mcp>. It will latch onto existing applications and expose them to AI agents as deterministic, verified MCP tools. When there is something to use, it will be published here under a later version.
