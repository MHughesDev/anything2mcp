# Address spellings, and what each check of where an address is says of each
# (decision 0240). One corpus, read by a test in each crate that asks whether
# a plain link stays on this machine:
#
#   auth      a2m-auth `link::loopback`, given `http://<spelling>/`
#   http      a2m-pack-http `link::plain_to_another_machine`, given `http://<spelling>/`
#   mcp       a2m-pack-mcp `mapping::plain_to_another_machine`, given `http://<spelling>/`
#   stream    a2m-pack-stream `wire::plain_tcp_address`, given the spelling
#   postgres  a2m-pack-data `postgres::server_of`, given the spelling as the surface's address
#   scope     a2m-core `ScopedHost::of_destination`, given the spelling
#
# A verdict is `here` (the address is this machine's loopback address, so a
# plain link to it may carry a credential), `away` (it may not), or `-` (the
# crate's own parser refuses the spelling, so the check is never asked).
# `away<here` is a tightening: the check said `here` before decision 0240 and
# says `away` now. Nothing may go the other way.
#
# A scope is the name of an `AddressScope`, with `+mapped` when the address
# was written as an IPv4 address inside IPv6 and `+zone` when it carried a
# zone.
#
# `<empty>` stands for the empty text and `<sp>` for a space. Columns are
# separated by spaces; a line that starts with `#` is a comment.
#
