# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in the repository, its issues and pull requests, and anywhere someone is acting for the project.

## In short

- Be respectful and considerate. Assume the other person means well.
- Criticize ideas and code, not people. Give reasons.
- Accept correction gracefully, and give it kindly.
- No harassment, no insults, no personal attacks, and no publishing of anyone's private information.

The full text at the link above is what binds; this summary is only a reminder.

## People and agents

Much of the work here is done by AI agents working for a maintainer. The same standard applies to what an agent writes as to what a person writes, and the maintainer it works for answers for it. Be as civil to someone's agent as you would be to them.

## Reporting

If someone's behavior here falls short of this, tell the maintainers privately. Use the repository's **Security** tab and **Report a vulnerability**, which opens a channel only maintainers can read, and begin the report with the word "Conduct". For abuse that GitHub itself should act on, use GitHub's own "Report content" link on the comment or profile.

Maintainers will read every report, keep the reporter's name private, and decide what to do under the enforcement guidelines of the Contributor Covenant.
